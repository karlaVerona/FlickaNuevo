# Flicka

Web application inspired by Letterboxd for managing and recommending movies.

This is the complete project: backend and frontend in the same repository.

## Technologies

- PHP / Laravel (backend)
- JavaScript, Vite, Tailwind CSS (frontend)
- Relational databases

## How to run it

Run the frontend and the backend separately, from Visual Studio.

The backend and the frontend must both be running for the app to work.
